# Magic Inventory App Frontend

Frontend for a Magic: The Gathering inventory management application built with React and TypeScript.

## Backend Repository

https://github.com/TU-USUARIO/magic-inventory-app-backend

## Tech Stack

- React
- TypeScript
- Axios
- Vite
- React Router

## Features

- Collection browsing
- Card filtering
- Card search
- Autocomplete suggestions
- Quantity controls
- Sorting
